# VetChart 차트 구조 정보 추출 프로그램 (베타)

동물병원 차트 프로그램을 [VetChart](https://earthdreamer22.github.io/vetchart-beta/)로 옮기는 **변환기를 만들기 위해**,
지금 쓰시는 차트 DB의 **구조**만 모으는 프로그램입니다. 소스 코드를 모두 공개합니다 — 무엇을 읽고 무엇을 보내는지 직접 확인하실 수 있습니다.

## 하는 일

1. 이 PC에서 쓰는 DB를 찾습니다 — Firebird(`.fdb`), MS SQL Server, MySQL/MariaDB, PostgreSQL
2. DB를 **읽기만** 합니다 (SELECT와 목록 조회만 — 쓰기·변경·삭제 없음)
3. 표마다 최대 500행을 이 PC 메모리에서 읽어 **값의 '모양'만** 요약합니다
4. 바탕화면에 결과 파일(`VetChart_구조정보_날짜.zip`)을 만들고 **미리보기**를 엽니다
5. 확인하시면 Gmail 쓰기 창과 파일 위치를 엽니다 — **프로그램이 혼자 보내지 않습니다.** 직접 첨부해서 보내 주세요

## 보내는 것 / 보내지 않는 것

| 보내는 것 | 보내지 않는 것 |
|---|---|
| DB 종류·버전, 표·칸 이름, 칸 형식, 행 수, 기본 키·외래 키 | 보호자 이름·전화번호·주소·이메일 |
| 비어 있는 비율, 글 길이(최소·평균·최대), 한글·영문·숫자 비율 | 동물 이름, 진료 내용, 메모 |
| 날짜·전화번호·주민번호·이메일·RTF·암호화처럼 **보이는 비율** | 직원·수의사 이름 |
| 형식 틀 (`####-##-##`, `가가가` — 숫자→#, 한글→가, 영문→A) | 금액·날짜의 실제 값 (자릿수·연도 범위만) |
| 코드 값 — 성별·종·상태처럼 짧고 **표본에서 5번 이상 나오는** 값만 | 드문 값, 사람 이름처럼 생긴 값, 파일·사진 내용 |

규칙은 [`extractor/profile.py`](extractor/profile.py)에 있고, [`tests/test_profile.py`](tests/test_profile.py)가 이름·전화번호 등이 결과에 남지 않는지 시험합니다.

DB 접속 비밀번호를 물어볼 수 있습니다 — **이 PC에서 접속에만 쓰고 저장하거나 보내지 않습니다.**

## 실행

- 차트 **서버 PC**(DB가 있는 PC)에서 진료가 끝난 뒤 `VetChart_Extractor.exe`를 실행하세요
- 서명되지 않은 프로그램이라 Windows가 경고할 수 있습니다 → [추가 정보] → [실행]
- 받은 파일이 이 저장소의 릴리스와 같은지 SHA-256으로 확인할 수 있습니다 (릴리스 설명에 적혀 있음)

## 직접 빌드

```
pip install -r requirements.txt pyinstaller
build.cmd
```
